# Protótipo de espectador Android

Sirva a raiz do repositório por HTTP local e abra /mobile/ em localhost. A página importa o motor WebRTC do cliente Windows e usa o serviço de salas existente. Cole um convite completo, entre e toque em Assistir quando houver uma transmissão. O navegador precisa de um contexto seguro (localhost ou HTTPS).

Este protótipo testa a recepção de tela, áudio e câmera. O APK, a captura no Android e o atualizador ainda não fazem parte deste protótipo.
