    Minha transmissão

    No seletor, escolha o jogo/janela e habilite o áudio. Se o Windows não oferecer essa opção, o vídeo terá aviso de ausência de áudio.

    Ajustes avançados

    O envio é dividido entre espectadores. Quatro amigos exigem até quatro cópias do vídeo.

    Apenas P2P direto com STUN gratuito. Redes incompatíveis não conectam; nenhum relay é ativado. Salas de 24h com renovação pelo criador.
